## 🔮 Retrospective: Example Session
- **Anti-Patterns Discovered:** The Engineering Lead attempted to use `TailwindCSS` utility classes (`bg-red-500`) instead of consuming the OKLCH tokens generated by the Design Director.
- **Token Wasters:** The UX Strategist generated 200 lines of unrelated user personas for a simple button state change.
- **New Heuristics:**
  - **For Engineering Lead:** NEVER use raw Tailwind color classes. Always use `var(--color-*)` from the theme artifact.
  - **For UX Strategist:** When the task is a micro-interaction or component update, skip the full persona generation and output only the direct user flow.
